EFI Data-led Research Methods

Choose a Text Analysis Tool

The choice of text analysis tool depends on the amount of programming you are comfortable with: would you like to avoid writing code altogether, or would you like to make use of your coding skills?

How much customisation would you need?

Depending on the complexity of your research questions and your coding skills, there is a vast array of possibilities you can explore.

Out-of-the-box options

If you are hoping to avoid writing code, then there are a series of resources you may want to check out.

  • AntConc is an open-source software that is free to download. It provides a user interface for text analysis that gives you many of the same capabilities as text analysis programming libraries. To learn how to use AntConc, check out the Library Carpentry resource in the self-guided learning options at the bottom of this page.
  • Voyant Tools is a web-based text reading and analysis environment. It is a scholarly project that is designed to facilitate reading and interpretive practices for digital humanities students and scholars, as well as for the general public.
  • Gale Digital Scholar Lab, which needs a University of Edinburgh EASE login, is an online tool for collecting datasets comprising content from the University of Edinburgh’s Gale Primary Sources purchases. These datasets can be analysed using open-source text analysis and visualisation tools built into the Digital Scholar Lab. Tools included are Ngram, Topic Modelling (Mallet), Named Entity Recognition, Parts of Speech (SpaCy), Sentiment Analysis (OpenNLP), Clustering (SciKit), and Term Frequencies (Lucene).
  • Google Cloud Natural Language allows you to apply machine learning algorithms to your texts.
  • MonkeyLearn can be used for easy keyword analysis.
  • LancsBox is a tool for the analysis of language.

Coding options

If you are comfortable writing code, try using Jupyter Notebooks, either by downloading the open-source software from the Jupyter Project or through the University-provided Noteable service. Downloading Jupyter Notebooks will allow you to run and save your Notebooks on your computer, so you will need to download programming languages and libraries such as Python and NLTK to your computer. Using the Noteable service will allow you to run Jupyter Notebooks in a web browser, and if you use the Language and Machine Learning Notebook, you will not need to download any programming libraries to your computer to conduct text analysis.

If you prefer, you can also write code in an integrated development environment (IDE) such as Atom or Visual Studio. In an IDE, you can use text analysis libraries with the Python programming language and its text analysis libraries such as NLTK, spaCy, and TensorFlow, as you can with Jupyter Notebooks outside of and within the Noteable service.

When programming text analysis functions and methods, Regular Expressions, often abbreviated as RegEx, are useful when looking for specific patterns of characters or words in your text or texts.
