EFI Data-led Research Methods

Obtain your Corpus

A corpus is defined in linguistics as a language resource consisting of a large and structured set of texts.

This will constitute the dataset you are going to work on, and the structure and length of it will depend on what kind of research questions you are trying to answer.

If your corpus has been created by someone else, you can simply download it. If you are creating your corpus yourself, or would like to modify a corpus someone else created, there are several tools you can choose from to obtain the text files you need.

Getting your corpus ready

If you are modifying an existing corpus, you can use programming languages such as R and Python to make your modifications. Some modifications you might consider include:

  • Changing the format of the files, for example, extracting information in Extensible Markup Language (XML) format and converting it to plain text (TXT) format.
  • Reorganising the files, for example, chronologically.
  • Filtering the files, for example, removing files that were not written by the particular author in whom you are interested.

Check out the Data Wrangling page for more information on modifying data.

Web scraping and other UoE resources

If you are creating your own corpus, you can download, scrape, or harvest text available online. Be sure to comply with copyright restrictions for anything you find online.

Many data can be free to consult but not free to use for text analysis. Check the usage rules of your data, or contact your local librarian if in doubt.

If you want to do text mining on social media platforms like Twitter, you may want to gather the tweets by searching them by queries or gathering them from certain users. Gathering this type of dataused to be very straightforward using social media provided API but in the last few years social media companies have changed the way these tools can be accessed/used by researchers. Twitter has cancelled the option of collecting data the research API for free that was given to researchers with legitimate research questions and it is now charging researchers the same way they charge private companies. Meta now has a Meta Content Library and API that gives access to "public" data stored in the various meta. There are also tools like the The Web Data Research Assistant (aka WebDataRA) or the Zeeschuimer plugin that will allow you scrape various platforms. Tools like this are incredibly useful but you will need to clear out your research proposal with your Ethics commitee because it may be in breach of the platforms TOC.

If you want to do text mining on other forms of text, such as news, customer reviews or comments from blogs, you can use web scrapers that crawl web data and gather specified information. To do so, you you would normally write a script in either Python or R (there are many libraries that you can use) but you need to use the same care mentioned above for social media data harvesting. When it comes to standard websites, what you are allowed to do when automatically scraping is normally stored in the "robots.txt" file. To access it just type the website homepage followed by /robot.txt: e.g. if you want to explore what can you scrape from the Guardian website you need to access https://www.theguardian.com/robots.txt

If you are familiar with coding, there are a series of packages that are being developed to do web scraping:

  • LIHKGr: the goal of the LIHKGr R package is to scrape text data on LIHKG, the Hong Kong version of Reddit, for analysis.
  • Socialreaper: a Python 3.6+ library that scrapes Facebook, Twitter, Reddit, YouTube, Pinterest, and Tumblr.
  • Snscrape: a scraper for social networking services. It scrapes things like user profiles, hashtags, or searches and returns the discovered items, such as the relevant posts.
  • Rvest: helps you scrape or harvest data from web pages.
  • RSelenium: uses the popular Selenium server to simulate an entire browser. This is more powerful but more complicated than rvest. You only really need to use it when interacting with websites that have dynamic content.

If you are based at the University of Edinburgh, there are a series of tools and resources that you can use to create your corpus:

  • ProQuest Workbench: ProQuest TDM Studio is a web-based platform that allows researchers to access and analyse large-scale textual data from ProQuest’s collections. Researchers can work together in a coding workbench in a Jupyter Notebook environment, building a project corpus and conducting data analysis, text mining, and visualisation. CDCS manages the University of Edinburgh’s ProQuest Workbench: please get in touch with us via email to discuss access.
  • Gale Digital Scholar Lab: Gale Digital Scholar Lab is an online tool for collecting datasets comprising content from the University of Edinburgh’s Gale Primary Sources purchases. These datasets can be analysed using open-source text analysis and visualisation tools built into the Digital Scholar Lab. Tools included are Ngram, Topic Modelling (Mallet), Named Entity Recognition, Parts of Speech (SpaCy), Sentiment Analysis (OpenNLP), Clustering (SciKit), and Term Frequencies (Lucene).
