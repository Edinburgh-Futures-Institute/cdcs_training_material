EFI Data-led Research Methods

Acquiring, gathering and cleaning the data

The first and most important step you will need to take is to identify, collect, and clean your data.

The type of text plays a decisive role in the subsequent tool selection. Some tools are specialised in certain types of texts such as tweets or long-form writing like a novel, others are designed for texts that talk about certain types of industries and therefore have a specialist vocabulary.

Using uncleaned data will skew the results of the analysis, so this step needs to be very accurate and you will need to keep a record of all the cleaning steps you performed on the data.

Gather your data

Before you get started, you need to think about the goal you want to achieve, and in what ways you want to gather your data.

If you want to do text mining on social media like Twitter, for example to analyse the sentiment of different tweets about certain topics, you may want to gather the tweets by searching them by queries or gathering them from certain users. Gathering this type of dataused to be very straightforward using social media provided API but in the last years social media companies have changed the way these tools can be accessed/used by researchers. Twitter has canceled the research API that was given researchers with legitimate research questions the options of collecting data for free and it is now charging researchers the same way they charge private companies. Meta has now a Meta Content Library and API that gives access to "pubblic" data stored in the various meta. There are also tools like the The Web Data Research Assistant (aka WebDataRA) or the Zeeschuimer plugin that will allow you scrape various platforms. Tools like that are incredibly useful but you will need to clear out your research proposal with your Ethics commitee because it may do so in breach of the platforms TOC.

If you want to do text mining on other forms of text, such as news, customer reviews or comments from blogs, you can use web scrapers that crawl web data and gather specified information. To do so you you would normally write a script in either Python or R (there are many libraries that you can use) but you need to use the same care mentioned above for social media data harvesting. When it comes to standard website what you are allowed to do or not when it come to automatically scraping is normally stored in the "robots.txt" file. To access it just type the website homepage followed by /robot.txt: e.g. if you want to explore what can you scrape from the Guardian website you need to access https://www.theguardian.com/robots.txt

You also need to consider in what format to store the data after collecting it. You can use web browser plugins with which users can extract information from any public website using HTML and export the data to the desired file format.

Data cleaning

Data cleaning is an important step that will take more time than any other step in text mining. It is vital because we want to remove words and symbols that do not have any impact on meaning. For example, if you want to analyse the sentiment of a novel, you need to remove content that has nothing to do with the main text of the plot, such as stop words. Then you need to convert the data into a structured data format that programmes or tools can directly use for sentiment analysis.
