Computer Drawing

3D data can be created using a broad array of software.

Some software is extremely precise and suitable for complex engineering tasks, others can be more approximate emphasising creative free-form modelling.

Depending on what you are trying to build you may want to use technical drawing or modelling software or a combination of the two.

Technical Drawing

If what you need is extreme precision and the model you are trying to build has mostly regular geometric features you should use technical drawing software.

The Autodesk Suite is among the most used software suites to build these models. Depending on the complexity of the object you are planning to build you can mostly use AutoCad and within this Inventor.

Autodesk is a proprietary software and some open source alternatives exist, such as FreeCAD, but they tend to have less functionality than the proprietary version. For architectural style drawing, among the most used software are Rhino and Sketchup.

Neither is open source, but they have cheaper educational licences and the University of Edinburgh holds licences for both of them. Expect to try out multiple programs when learning what’s right for you. AutoDesk Inventor is very good for making complex drawings of musical instruments, while Rhino works very well to reconstruct complex architectures like palaces and churches.

Depending on your intended uses, one or more software programs might be more appropriate than others.

Most of these software packages have very active online communities, so that would be the first step to start making your decision.

Model Drawing

If the model you are planning to build has less regular geometric features, for example if you intend on sculpting something, there are a series of software programmes that will help you with these kinds of tasks.

These software programmes can also be used if you intend to both scan and draw an object. For example, you can scan a real-world object and implement it with drawn-from-scratch features.

This approach is used often in Cultural Heritage to perform what is called “digital restoration”, i.e. virtually integrating missing pieces from an archaeological or historical object.

Meshmixer and Blender are very useful for processing 3D scan data as well as free-form creations. Often scanned objects have a very complicated geometry and therefore you will need to simplify their geometry to be able to work with them in these software packages.

If you want to discover more on processing 3D scan data go to step 2 3D Data Wrangling.
